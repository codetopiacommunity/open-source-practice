# FAQ

**Do I need to know how to code to contribute?**

No. Many contributions are documentation, typo fixes, or adding yourself
to a list. You do not need to write a single line of code.

**What should my branch name look like?**

Use a short prefix that describes the type of change, followed by a
slash and a brief description. For example: `fix/typo-in-about` or
`docs/add-name-to-contributors`.

**How do I claim an issue?**

Leave a comment on the issue saying you would like to work on it. A
maintainer will assign it to you. Do not start working on an issue that
is already assigned to someone else.

**How many issues can I claim at once?**

One at a time. Finish and close your current one before claiming another.

**My pull request has a conflict. What do I do?**

This is normal. See the
[Resolving a Merge Conflict](https://github.com/codetopiacommunity/opensource-onboarding/blob/main/07-resolving-a-merge-conflict.md)
guide for a step-by-step walkthrough.

**Who reviews my pull request?**

A Codetopia maintainer will review it. Reviews usually happen within a
few days. If you have not heard back after a week, feel free to leave a
polite comment or ask in Discord. Response times are typically faster
there.
