# Contributors

Everyone who makes their first pull request here adds one small file to
this folder: their own. This is usually your very first contribution.

## How to add yours

1. Create a new file in this folder named after your GitHub username,
   ending in `.md`. For example: `kofi-mensah.md`.
2. Write a few lines about yourself:

   ```markdown
   # Your Name

   - From: Your city, your country
   - Learning right now: what you are learning
   - Fun fact: one thing about you
   ```

3. Open a pull request.

## Rules

- **Name the file after your GitHub username**, so two people with the
  same name never clash.
- **Only add your own file.** Do not edit anyone else's.
- One file per person.

Because everyone adds their own file, two pull requests never touch the
same file, so there are no merge conflicts to worry about.
